# A Simple Proposal 💖

An interactive, romantic web experience designed to ask that special someone a very important question!

## Features

✨ **Interactive Animation** - Animated typing text for the proposal question  
🎶 **Background Music** - Soft romantic music plays on interaction  
💖 **Floating Hearts** - Animated hearts float across the background  
🎉 **Confetti Effect** - Celebratory confetti explosion on "Yes"  
😂 **Funny Reactions** - Cute animated reactions when trying to click "No"  
🎨 **Beautiful UI** - Clean, modern design with Tailwind CSS

## How to Use

1. Open `index.html` in a modern web browser
2. Click anywhere to start the experience
3. Follow the interactive prompts

## Files

- `index.html` - Main HTML structure
- `script.js` - JavaScript logic and interactions
- `style.css` - Custom styling
- `kiss.gif` - Celebration GIF (on "Yes" answer)

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS framework
- [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti) - Confetti animation library
